# desk dockt

Free, MIT-licensed Android mouse and keyboard sharing with a Python desktop host.

- [Android companion and build instructions](android-companion/README.md)
- [Desktop host and installation](wayland-host/README.md)
- [Compatibility](wayland-host/COMPATIBILITY.md)
- [F-Droid submission preparation](fdroid/submission.md)

Version 0.2.4. Use LOCAL (cable / ADB) or optional secure Wi-Fi. Android 8+, targeting Android 17. Windows/macOS backends are implemented; hardware validation remains pending.

New implementation inspired by DeskDock by Florian Draschbacher. Original/repaired APKs, reverse-engineering work products and private signing material are not included.
