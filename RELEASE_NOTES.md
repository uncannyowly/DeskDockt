# desk dockt 0.2.4

Free MIT-licensed Android companion and Python desktop host.

- New one-time LOCAL (cable) / WiFi (net) setup.
- Simpler phone home; configuration lives in Settings.
- Saved Connect on start; debugging, input, keyboard and network shortcuts.
- Other connection buttons switch between cable and Wi-Fi setup.
- ADB needs no app pairing code; direct Wi-Fi retains TLS pinning and pairing.
- Desktop settings precede Start/Stop; tray actions follow session state.
- Screenshot key, text clipboard sharing, mouse/keyboard input and tray hiding.

Android 8+, targeting Android 17. Windows/macOS source backends are implemented but hardware validation is pending. Wayland requires InputCapture portal/libei. PC video streaming is not included.

Downloads in the README are signed release artifacts hosted at uncannyowly.com. Original/proprietary DeskDock APKs and signing keys are excluded. F-Droid submission is not approval or availability.
